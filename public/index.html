YouTube authentication

            
Get YouTube cookies for yt-dlp

          

          
        

        
Cookies let yt-dlp use your signed-in YouTube session for content that requires an account, such as private playlists, age-restricted videos, and members-only content.

        
    
          
  1. 
            Install a cookies.txt exporter and allow it in private windows.
            Use Get cookies.txt LOCALLY for Chromium or cookies.txt for Firefox. Do this before opening the private window.
            Chrome: Extensions → Manage extensions → find the exporter → Details → turn on Allow in Incognito. Firefox: Add-ons and themes → Extensions → select the exporter → set Run in Private Windows to Allow.
          
    2. 
          
  2. 
            Open a new private or incognito window.
            Keep exactly one private tab open and sign in to YouTube. Consider using a separate account rather than your main account.
          
    3. 
          
  3. 
            In that same tab, open https://www.youtube.com/robots.txt.
            Do not open another YouTube tab after this.
          
    4. 
          
  4. 
            Use the browser extension to export the YouTube cookies.
            Choose Netscape format if the extension asks. It will download a cookie file, usually named cookies.txt. Then close the private window and do not reopen that session.
          
    5. 
          
  5. 
            Upload the file here.
            Media Baker keeps only YouTube cookie records and supplies them only to YouTube requests made by yt-dlp.
          
    6. 
        

        

          Treat cookies.txt like a password.
          Anyone with the file may be able to use your signed-in session. Do not share it, and only use account cookies when needed. Using an account with yt-dlp may put that account at risk.
